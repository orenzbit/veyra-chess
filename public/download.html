מה מתקינים?

  1. פתח את ה־Windows Connector.
  2. הדבק את כתובת ה־Veyra שקיבלת מ־Netlify.
  3. שמור.
  4. לחץ לפתיחת Veyra.

ה־Connector לא שומר סיסמת Admin או מפתחות API.

What do I install?

  1. Open the Windows Connector.
  2. Paste the Veyra address you received from Netlify.
  3. Save it.
  4. Open Veyra.

The Connector does not store Admin passwords or API keys.

התקנה ללא Connector

אפשר גם להתקין את האתר כאפליקציית PWA דרך הדפדפן, בלי תוכנה נוספת.

Without the Connector

You can also install the website as a PWA from your browser without extra software.
