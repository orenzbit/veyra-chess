Privacy Policy

1. Data we may collect

  • Account details: email, username, full name, birth date and country.
  • Terms and Privacy acceptance, including document versions and acceptance time.
  • Game and training data the user provides or creates in Veyra when needed for training systems.
  • Limited aggregate Adaptive signals when the user enables Adaptive.
  • Technical data needed to operate and secure the service.
  • Private-beta access request data: email address, request time, code expiry, failed-attempt count and basic security data needed to prevent abuse.

2. Why we use it

Data is used to create and secure accounts, verify email, run Coach, Adaptive Bots and game review, save progress and provide support.

3. Training data

Game and training data associated with the account is kept while the account exists so training systems can learn recurring patterns and personalize coaching. When shared Adaptive improvement is enabled, only limited aggregate signals, not raw PGNs, are sent to the shared learning path.

4. Deletion

The user can delete the account after explicit confirmation. Active account and training data in the application's tables is deleted. Technical backups may remain temporarily under normal infrastructure backup cycles.

5. Providers

Netlify is used for hosting/runtime, Supabase for accounts, data and email verification, and an email delivery provider for sending the one-time private-beta access code to the operator. Chess.com and Lichess imports are user-initiated.

6. Email

Email verification uses Supabase's built-in email system during the beta. Private-beta access requests also send the operator a one-time access code so the operator can decide who receives it. Email is not used for marketing without separate consent.

7. Security

Server secrets remain server-side. Passwords are not stored in plaintext by Veyra.

8. User controls

Users can request account information, update account details and delete the account through the available interface and applicable law.
