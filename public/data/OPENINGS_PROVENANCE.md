# Openings provenance — Veyra Chess

- **Format:** the repertoire module format from daxaur/tabia (MIT): `{ id, name, color, eco?, oneLiner, trunk, groups, lines:[{ id, name, group, star, idea, moves:[[SAN, comment?]] }] }`. Every opening in Veyra Chess uses it.
- **Sources (all MIT):**
  1. daxaur/tabia, © 2026 dax — 14 hand-written repertoires (Blackmar-Diemer, Jobava London, Budapest, Alien, Benoni Gambit, Benoni, Queen's Gambit, Ruy Lopez, Italian, Sicilian, French, Caro-Kann, Scotch Gambit, Vienna Gambit). Included unchanged in content; see `data-src/daxaur/LICENSE`. Only these data files were taken. The vendor files of that repository (Stockfish and piece sets) were NOT taken.
  2. Veyra Openings — written for Veyra Chess (`data-src/veyra-openings.txt`), with one-liners and ideas by the chess-masters panel (`data-src/masters-notes.json`). No third-party opening table was copied.
     Batch 1 (EXTENSION 7, owner-approved 2026-10-26) adds 40 lines: 31 in existing families (Petrov/Stafford Gambit, Italian/Legal Trap and Traxler, London System incl. Barry-style, Queen's Gambit Declined/Albin Countergambit, Caro-Kann Fantasy, Scandinavian/Icelandic Gambit) and 9 in two new Black families, Scholar's Mate Defense (4 lines) and Hedgehog System (5 lines). Names are traditional or descriptive. Move orders are Veyra-authored and were checked on the project's own engine; the one-liners and ideas for the two new families were written fresh for `masters-notes.json`.
- **Removed:** the earlier 3,803-line `openings.json`, whose structure matched the lichess-org/chess-openings table (CC0). Batch lines under data-src/openings-batches/ were added in October 2026; their names and moves were read from lichess.org opening pages (see the `# source:` comments in each batch file). (The optional "import my games from Lichess" feature calls Lichess's public API at runtime and ships no Lichess data.)
- **Validation:** `npm run build:openings` replays every line move-by-move on the rules engine (js-chess-engine, MIT) and fails on any illegal move. The repertoire now has 1,236 lines (1,235 unique move sequences). The 1,144 lines that were validated earlier also passed daxaur/tabia's own validator and an independent engine (test-only, not shipped). The 40 batch-1 lines (EXTENSION 7) were not run through that validator or independent engine; they were checked with the project's own review loop (`analyzeGameMoves` in `src/review-metrics.ts`).
- **Tiers:** Veyra lines carry `tier` in `public/data/openings.json`: `1` = core set, `2` = extension approved on 2026-10-04. Tier-2 names are traditional where well known, otherwise descriptive, and have not been reviewed by a second person. The batch-1 lines (EXTENSION 7) are tier 1.
- **ECO codes:** Veyra lines have none (third-party classification). The `eco` fields of the 14 daxaur repertoires are kept as authored.
- **Outputs:** `data/repertoire/*.js` (module format), `public/data/repertoire.json` (bundle), `public/data/openings.json` (flat book used by Review).

## Batch lines (`data-src/openings-batches`)

- Batch files A2-spanish, A4-kg-philidor-others, B1-sicilian-main, B4-pirc-modern-alekhine-scand, D2-catalan-benoni-dutch and E1-flank: names and moves read from lichess.org opening pages.
- Every batch line is validated by `scripts/check-openings-source.mjs` (legal moves, canonical SAN, unique names, parent lines) and replayed by `npm run build:openings`.
