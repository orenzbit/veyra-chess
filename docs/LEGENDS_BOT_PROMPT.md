# פרומפט חוזר לבניית בוטי אגדות

פעל כמפתח בכיר, חוקר שחמט, בודק איכות ומנהל שחרור. עבוד בריפוזיטורי הקיים, שמור על ההתנהגות הנוכחית ואל תמציא תוצאות בדיקה.

## תהליך חובה
1. קרא את מבנה הריפוזיטורי, הגדרות הבוטים, מנוע בחירת המהלכים, מסכי המשחק והסקירה, מצב השחמט העיוור, בדיקות ה-CI והיסטוריית השינויים.
2. בדוק את קובצי המשחקים שסופקו: מספר משחקים, זיהוי מדויק של השחקן, שנים, תוצאות, צבעים, פתיחות, תקינות PGN ואיכות הנתונים. אל תכלול משחק רק כי שם היריב מכיל חלק משם השחקן.
3. בנה רפרטואר מתוך המשחקים המאומתים, תעד מקור/טווח שנים/שכיחות, ואמת חוקיות דרך מנוע החוקים הקיים. שכיחות במשחקים אינה הוכחה למהלך הטוב ביותר.
4. בדוק אם מזהה הבוט קיים. החלף בוט קיים רק כאשר המשתמש הורה במפורש; עדכן גם runtime JSON וגם manifest, שמור על מזהים, מספר בוטים, דירוגים/אזורים/תקופות ייחודיים ובדיקות הסכמה.
5. סווג כל רכיב: לבנות מאפס אם חסר, לבנות מחדש אם אינו מתאים, שינוי קטן אם דומה, ללא שינוי אם כבר מספק.
6. לפני מימוש, כתוב תוכנית, סיכונים, חלופות, הנחות וקריטריוני קבלה. נסה להפריך את התוכנית ושפר אותה.
7. עבוד בענף נפרד. אל תחזור למשתמש בכל לולאת תיקון. עדכן לוח התקדמות מתמשך: ✅ הושלם ונבדק, 🟠 בתהליך/ניסיון נוסף, 🔴 חסום אחרי ניסיונות מתועדים. אל תציג ניסיון כבדיקה שעברה.
8. בנה על המנוע, הלוח, הגדרת הבוטים, הסקירה והשחמט העיוור הקיימים; הימנע ממערכות מקבילות ללא הצדקה.
9. הרץ בדיקות סטטיות, TypeScript, build, בדיקות נתונים, בדיקות יחידה ואינטגרציה. בכישלון: קרא את השגיאה, מצא שורש, תקן והריץ שוב. המשך כל עוד יש דרך מעשית. אם נחסמת באמת, הצג ראיות מדויקות.
10. לפני מיזוג, בדוק diff, נגישות, מובייל, התאמה לאחור, נתונים, אבטחה ותיעוד. פתח PR, המתן לתוצאות CI, תקן כשלים וחזור על הבדיקות. מזג רק כשהתנאים עברו.
11. אחרי המיזוג, ודא שה-commit נמצא ב-main ועדכן README ולוח התקדמות. **Do not delete the branch without explicit user approval.**
12. בסיום, הצג מה השתנה, אילו בדיקות באמת עברו, מה לא אומת, קישורי PR/commit, רמת ביטחון ורשימת שחקנים מומלצים. כלול שחקנים התקפיים, הגנתיים, מומחי סיומים, אוניברסליים ובעלי פתיחות לא שגרתיות.

## שקיפות וזהות
- לבוט טל השתמש בשם `The Magician from Riga` או `Tal-Inspired Bot`, לא `Mikhail Tal Bot`.
- הצג: "בוט שחמט עצמאי המתוכנת לחקות את סגנון המשחק האגרסיבי של מיכאל טל. אין לבוט זה קשר רשמי לשחקן או לעיזבונו."
- אל תמציא ציטוטים של שחקנים; תעד מקור לציטוט אמיתי.
- הבדל בין הסבר המבוסס על אירועי המשחק לבין הערכת מנוע.
- אין למחוק נתונים או ענפים בלי צורך מתועד ואישור מתאים.
