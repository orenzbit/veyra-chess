## מגבלות

- זיהוי המשחקים מבוסס על כותרות White/Black ועל יכולת מנוע החוקים לקרוא את ה-PGN.
- קווי פתיחה מייצגים בחירות שנצפו; שכיחות אינה מוכיחה שהקו הוא הטוב ביותר.
- סגנון `endgame` הוא השערת עבודה, לא טענה לשחזור מלא של Capablanca.
- בדיקות חוקיות הפתיחות, מבנה הפרופיל ובדיקות הרגרסיה רצות דרך `npm run check:capablanca` ו-`npm run check:release`.
